# SkillWiki 论文实验复现说明

本目录提供全部 4,572 个任务回答的模型原答、系统最终输出与评分依据，以及 18 个更新提案；保留原始失败、后续修订、资格验证、治理、发布和恢复证据。离线命令只需 Python 3.10+ 标准库，不需要 API 密钥，不调用模型。

## 从哪里开始

在仓库根目录运行：

~~~bash
python public-experiments/verify.py
python public-experiments/reproduction/rescore.py
python public-experiments/reproduction/reproduce_tables.py
~~~

第一条检查原公开包的材料与计数；第二条使用归档评分器重新评分全部原答与最终输出；第三条从独立评分及治理收据重建论文两张表和对应扩展结果，发现差异即失败。不是仅检查汇总数字是否一致。

保存新评分与表格，或展开所有证据：

~~~bash
python public-experiments/reproduction/rescore.py --output reproduced-scores
python public-experiments/reproduction/reproduce_tables.py --output reproduced-tables.json
python public-experiments/reproduction/extract.py extracted-evidence
~~~

输出目录须尚不存在。展开后可按逻辑归档路径查看输入、提示词、候选、来源、评分合同、证明、冻结实现与历史执行脚本。原始哈希用于追溯，导出哈希用于核对脱敏文件；两者有区别。本机路径已替换、供应商标识已哈希、凭据已脱敏。历史脚本带原工作区路径和已消耗运行保护，作为实现参考，不能直接假装成通用运行命令。

## 模型与版本

原调用使用 API 别名 `deepseek-flash`，温度 0，关闭思考，不自动重试；任务答案/提案输出上限为 2,048/4,096 tokens。论文称谓 DeepSeek-V4.1-Flash-1017 根据官方 2026-10-17 更新记录补充；实际实验为 2026-11-07 至 11-09。别名可能后续变化，新运行应登记日期、返回模型和指纹。

各批次保留各自冻结产品、候选与来源身份。发布复现包的仓库提交用于定位材料，不将当前产品版本倒认作历史实验版本。

## 可选的新模型调用

先预览选择，不产生网络请求：

~~~bash
python public-experiments/reproduction/replay_requests.py --call-index 1
~~~

确需新付费调用时，在环境变量中设置 DEEPSEEK_API_KEY，再显式执行：

~~~bash
python public-experiments/reproduction/replay_requests.py --call-index 1 --max-calls 1 --execute --output new-model-run
~~~

脚本保存新产物、不覆盖历史、不自动重试，遇到传输失败停止。这是原提示词与生成参数的模型请求重放；系统最终输出处理、发布和恢复还涉及冻结实现与状态，不能用请求重放替代。当前产品操作见仓库 USER_GUIDE.zh-CN.md。整理本包时没有新增付费模型调用，也没有宣称全套历史产品状态迁移已成为一键重跑。

## “修订”是谁做的

后续改进是由已发现失败推动的开发修订：工程人员补充分离请求/响应来源范围的机制，以及通用检查指导；模型生成提案，再经系统绑定、资格验证、人工授权发布和恢复重验。U06 R2 的通用指导由工程人员撰写，不能表述为模型自主修改了产品。对应实验支持更新与证据治理流程及修订后候选的能力，不证明所有失败均能自主修好。
